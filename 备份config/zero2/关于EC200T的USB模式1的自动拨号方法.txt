方案一：USB热插拔自动拨号（首次插入/启动时触发）
	创建热插拔脚本 /etc/hotplug.d/usb/10-ec200t：
	
	内容：
	
#!/bin/sh

# 匹配 EC200T 模块 (VID: 2c7c, PID: 6026)
if [ "$PRODUCT" = "2c7c/6026/0" ] && [ "$ACTION" = "add" ]; then
    # 等待系统完全识别设备
    sleep 3
    
    # 发送拨号命令
    echo -e "AT+QNETDEVCTL=1,1,1\r\n" > /dev/ttyUSB2
    
    # 记录日志
    logger "EC200T: Hotplug triggered dial-up (AT+QNETDEVCTL)"
fi

	赋予执行权限：chmod +x /etc/hotplug.d/usb/10-ec200t




方案二：定时保活脚本（断线自动重连）
	创建保活脚本 /usr/bin/ec200t-keepalive.sh：

#!/bin/sh

# 检查 usb0 接口是否获得有效 IP
if ! ifconfig usb0 | grep -q "inet addr:"; then
    logger "EC200T: usb0 has no IP, attempting reconnect..."
    
    # 触发拨号
    echo -e "AT+QNETDEVCTL=1,1,1\r\n" > /dev/ttyUSB2
    
    # 如果多次失败，可考虑重启模块（可选，先注释掉）
    # echo -e "AT+CFUN=1,1\r\n" > /dev/ttyUSB2
    # sleep 5
    # echo -e "AT+QNETDEVCTL=1,1,1\r\n" > /dev/ttyUSB2
fi

	赋予执行权限：chmod +x /usr/bin/ec200t-keepalive.sh
	添加到 crontab（每分钟检查一次）：crontab -e
	crontab中添加：* * * * * /usr/bin/ec200t-keepalive.sh
	
测试与验证：
1、测试热插拔脚本：拔掉再插入模块，然后查看日志：logread | grep EC200T

2、测试保活脚本：手动运行一次：/usr/bin/ec200t-keepalive.sh

3、检查 IP 获取：ifconfig usb0

AT+QNETDEVCTL=1,1,1 这个命令通常不会在已连接状态下造成问题，但为了更健壮，可以在热插拔脚本中增加一个简单的“幂等性”检查
# 检查是否已经有 IP，如果有则跳过拨号
if ifconfig usb0 | grep -q "inet addr:"; then
    logger "EC200T: usb0 already has IP, skipping dial-up."
    exit 0
fi



热插拔脚本：解决模块首次插入或系统启动时的自动拨号。
定时脚本：解决运行过程中因信号波动或模块异常导致的断线重连。
日志记录：方便你排查问题，确认是否触发成功。
